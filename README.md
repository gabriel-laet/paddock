# paddock

An inbox host. TUI and web.

Sources admit items. Organizers label them. You work an inbox.

## nouns

- **item** — one thing that arrived, stripped of its source's shape
- **source** — a plugin that admits items
- **label** — a mark an organizer put on an item
- **inbox** — a named question over the pile (labels + sources + sort), not an account

Organizer is a plugin role, not a user-facing word. Heuristics and LLMs are both just organizers.

## surfaces

- TUI (`paddock`)
- web

No desktop app yet.

## status

Early. The model is the product. Adapters and UI come next.
